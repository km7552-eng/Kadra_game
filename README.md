### Why it's a good choice

- Simple keyboard controls (Spacebar to jump).
- Obstacles move toward the player.
- Earn points based on distance survived.
- Game gets faster as time passes.
- Collision with an obstacle means Game Over.
- Easy to add sound effects, animations, and a restart button later.

Difficulty: Beginner-friendly (approximately 4/10).
